# ЧелБлокс

Браузерная игра про живой город в стиле Roblox. Ты гуляешь по улицам, следишь за порядком и помогаешь службам справляться с происшествиями: пожарами, преступниками и другими задачами. Чем больше удачных действий — тем сильнее твоё влияние, лучше одежда персонажа и стабильнее город.

Игра открывается в браузере, не требует установки. Можно продолжить с того же места после перезагрузки или начать новый город с нуля.

## История версий

### v0.3.2

- **Десктопный интерфейс** — исправлена раскладка: уведомления по центру, боковые панели не перекрывают друг друга и нижние кнопки
- **Документация** — схема HUD в PROJECT.md, README и PLAN.md

### v0.3.1

- **Мобильная версия** — touch-управление, компактный HUD, выдвижные панели
- **Автообновление** после деплоя (кэш сбрасывается по метке сборки, localStorage сохраняется)

**Интерфейс на десктопе** (актуально с v0.3.2):
- **Вверху:** очки, индекс города, звук / справка / пауза
- **Слева:** задания (преступники, пожары)
- **Справа:** шкалы влияния (игрок, службы, город)
- **По центру сверху:** уведомления
- **Внизу:** полиция, пожарные, бег, прыжок, камера

### v0.2.1

Базовый функционал игры:

- **3D-город** — дороги, здания, деревья, ездящие машины
- **Персонаж игрока** — ходьба, бег, прыжок, обзор камерой
- **Жители и службы** — полиция, пожарные в красной форме, преступники, горожане
- **События** — пожары на зданиях и появление преступников; можно вызвать пожарных или полицию
- **Диспетчер** — кнопки для отправки служб на задание
- **Шкалы влияния** — отдельно для каждой службы и для игрока; от них зависит состояние города
- **Прогресс игрока** — за успешные действия растёт влияние и меняется одежда (несколько уровней)
- **Сохранение** — игра запоминает позицию, жителей и прогресс; при возврате можно продолжить
- **Новый старт** — случайное появление игрока и жителей; кнопка «Начать сначала» для полного сброса
- **Настройки** — режим «Низкие настройки» для более плавной игры на слабых устройствах
- **Звук** — музыка и звуки событий (сирена, пожар, арест и др.)
- **Версия игры** — отображается в интерфейсе
